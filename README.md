# SeaDB Admin Docs

Manual for SeaDB server.

The web site: https://seacloud-lab.github.io/seadb-admin-docs/

## Serve docs locally

These docs are built using 'mkdocs'. Install the tooling by running:

```
pip3 install mkdocs-material mkdocs-awesome-pages-plugin mkdocs-material-extensions mike
```

Start up the development server by running `mkdocs serve` in the project root directory. Browse at `http://127.0.0.1:8000/`.
